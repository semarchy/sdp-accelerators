This file explains how to import the dashboard into the Retail Customer 360 application.

Instructions:
    1- rename the archive file "RetailCustomer360Analytics.rename_to_zip" to RetailCustomer360Analytics.zip
    2- On the SDP homepage go to Tools -> Dashboard Builder
    3- Select Import Application
    4- Drag & Drop RetailCustomer360Analytics.zip
    5- Once imported go to Datasources > Click on the existing datasource and set the datasource to the one where the data product has been deployed
    7- Save
