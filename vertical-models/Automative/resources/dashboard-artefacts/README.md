# Dashboard Artefacts

This folder contains dashboard artefacts for the Automotive / Manufacturing accelerator.

The dashboard files are stored with the `.rename_to_zip` extension to match the accelerator deployment convention used by the reference CorporateFinance package.

Before importing manually, rename the files back to `.zip` if required by the import tool or UI.

| File | Description |
| --- | --- |
| `ManufacturingIndustryModel.rename_to_zip` | Manufacturing industry model dashboard export. |
| `Manufacturing_Stg_Profiling.rename_to_zip` | Manufacturing staging / profiling dashboard export. |
